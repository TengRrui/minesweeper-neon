# 扫雷游戏设计

## 目标

在 `扫雷游戏` 目录中提供一个无需安装、无需构建步骤、双击 `index.html` 即可游玩的中文扫雷网页游戏。游戏需要在桌面和手机窄屏下都能使用，具备清晰的状态反馈、完整的基础扫雷规则和可重玩的局间流程。

## 设计决策

### 方案比较

1. **Canvas 棋盘**：适合大量动画和完全自定义的绘制，但需要额外处理格子命中、键盘焦点和辅助技术语义。
2. **原生 DOM + CSS Grid**（采用）：每个格子是一个按钮，天然支持点击、键盘焦点、ARIA 标签和响应式布局；棋盘规模有限，性能足够。
3. **第三方框架或构建工具**：可以拆分组件，但会引入安装和启动成本，不符合“放入目录即可运行”的目标。

### 总体架构

- `index.html`：页面语义结构、控制区、棋盘容器、结果弹层和操作提示。
- `styles.css`：霓虹控制台视觉、响应式布局、格子状态、动画与无障碍动效降级。
- `src/game-core.js`：与 DOM 无关的棋盘数据结构、邻居计算、布雷、邻雷计算、区域揭示、标记和胜利判断。
- `script.js`：难度配置、页面渲染、首击保护流程、计时、胜负结算和本地最佳成绩。
- `README.md`：运行方式、操作方式和规则说明。

游戏状态单向流动：难度选择或重新开始 → 初始化空棋盘 → 首次揭示时布雷 → 计算邻雷 → 用户揭示/标记 → 检查胜负 → 展示结果并保存最佳时间。雷区数据只保存在当前页面内存中；最佳成绩按难度存入 `localStorage`，存储不可用时不影响游戏。

## 功能范围

- 三档难度：初级 `9 × 9 / 10 雷`、中级 `16 × 16 / 40 雷`、专家 `30 × 16 / 99 雷`。
- 首击保护：首个揭示格和其邻域不放雷，并从首击位置自动展开安全空白区域。
- 左键/触摸揭示格子，右键切换旗帜；触摸设备提供独立的“标记模式”按钮，避免依赖右键。
- 旗帜数量计数，不允许标记超过当前雷数；已揭示格子不能被标记。
- 双击数字格快速标记周围未揭示格，并在周围旗帜数等于数字时自动揭示邻格。
- 状态栏显示剩余雷数、计时器、当前难度与最佳成绩；计时从首次揭示开始，最多显示 `999` 秒。
- 新局按钮随时重置当前难度；难度切换自动开启新局。
- 踩雷后显示所有雷并标出错误旗帜；胜利后标记剩余雷并展示用时。
- 结果弹层提供“再来一局”；键盘支持聚焦格子、Enter/Space 揭示、F 标记、R 重开。
- 使用 CSS 动效提升揭示与胜负反馈，并遵循 `prefers-reduced-motion`。

## 核心数据模型

每个格子包含：

```js
{
  index: number,
  isMine: boolean,
  isRevealed: boolean,
  isFlagged: boolean,
  adjacentMines: number
}
```

局状态包含：

```js
{
  difficulty: 'beginner' | 'intermediate' | 'expert',
  rows: number,
  cols: number,
  mineCount: number,
  cells: Cell[],
  firstMove: boolean,
  status: 'ready' | 'playing' | 'won' | 'lost',
  flagsUsed: number,
  revealedSafeCells: number,
  elapsedSeconds: number
}
```

## 交互与错误处理

- 右键菜单在棋盘区域禁用，并用 `preventDefault` 将右键转为标记。
- `localStorage` 读取/写入使用 `try/catch`；异常时显示当前局，但不阻断游戏。
- 已结束的棋盘忽略后续操作，避免在结算后继续变更状态。
- 计时器只在 `playing` 状态运行，清理旧定时器后再启动新局，避免多重计时。
- 所有格子按钮动态更新 `aria-label` 和 `aria-pressed`，结果状态同步到 `aria-live` 区域。

## 验收标准

1. 直接打开 `index.html` 可以开始一局，不依赖网络或第三方包。
2. 三档难度的棋盘尺寸、雷数和计数正确。
3. 首击永远安全；揭示空区会连锁展开；数字与周围雷数一致。
4. 左键揭示、右键标记、触摸标记模式和键盘操作均可用。
5. 踩雷、胜利、错误旗帜、重新开始、切换难度和计时流程正确。
6. 桌面宽屏与手机窄屏没有横向溢出，信息层级清晰。
7. 核心操作、状态和提示文字使用简体中文；装饰性短标签可保留英文。
8. 通过语法检查和可重复的浏览器交互检查，且无控制台错误。
